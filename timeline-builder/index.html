Let's get your timeline set up. This takes about 3 minutes.
Used as default "Added By" in the sheet
Set up your Google Sheet — this is where your team enters data.
Instructions
  1. Download the setup script below
  2. Open a blank Google Sheet
  3. Click Extensions → Apps Script
  4. Delete any existing code, paste the script
  5. Click Save, then Run → runSetup
  6. Authorize when prompted (one time only)
  7. Come back here and click Next
The script will ask for your timeline name — type: your timeline name
It creates all columns, formatting, Drive folder, and upload button automatically.
Already set up a sheet? Skip to Step 3 →
Almost done — paste your sheet URL to connect the app.
Before connecting
  1. In your Google Sheet: File → Share → Publish to web
  2. Select your timeline tab, choose CSV, click Publish
  3. Then copy the sheet URL from your browser address bar (not the publish URL)

🌐 Export Viewer

This generates a standalone viewer file — no editing controls, just the timeline. Upload it to GitHub Pages and embed it on your Squarespace page with a single line of code.

Sheet Connection

Viewer Options

After Downloading

  1. Upload timeline-viewer.html to your GitHub repository
  2. Go to GitHub → Settings → Pages → enable GitHub Pages
  3. Your viewer URL will be:
    https://yourusername.github.io/timeline-viewer.html
  4. In Squarespace, add a Code Block and paste:
<iframe src="https://yourusername.github.io/timeline-viewer.html" width="100%" height="900px" frameborder="0" style="border:none"></iframe>
