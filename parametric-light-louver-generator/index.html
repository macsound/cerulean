Hosting on GitHub Pages / Jekyll

This single-page web app is fully static and self-contained. You can host it on GitHub Pages with Jekyll using one of these options:

Option A: Raw HTML Page (Recommended)

Save this file as index.html inside your Jekyll repository. Add this Front-Matter snippet to the top of the file:

---
layout: null
---

Option B: Embedded in Existing Theme

To maintain your Jekyll theme header and footer, create a markdown page (e.g. louver.md):

---
layout: page
title: Louver Generator
---
