Hosting on GitHub Pages / Jekyll

This single-page web app is fully static and self-contained. You can easily host it on GitHub Pages with Jekyll by following one of these two options:

Option A: Raw HTML Page (Recommended)

Save this file as index.html inside your Jekyll repository. Add this Front-Matter snippet to the top of the file so Jekyll passes it cleanly:

---
layout: null
---

Option B: Embedded in Existing Theme

If you want to keep your site navbar and footer, paste the HTML body contents into a standard page markdown file (e.g., louver.md) with:

---
layout: page
title: Parametric Louver Generator
---
